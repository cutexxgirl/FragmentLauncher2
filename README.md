# Fragment Launcher

Desktop launcher for a singleplayer Minecraft modpack.

## Stack

- Tauri 2 with Rust commands
- SvelteKit, TypeScript, Tailwind CSS
- shadcn-svelte-ready project structure
- Tauri updater plugin prepared for later update wiring

## Development

```sh
npm install
npm run dev
```

Tauri development requires Rust:

```sh
npm run tauri:dev
```
